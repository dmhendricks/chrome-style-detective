Edge-case playground

Specimens for the sticky-hit / transform work. Arm Style Detective (Alt+Shift+S), then hover each card. The live log below shows elementFromPoint vs layout size while you hover — useful even without the extension.

1. pointer-events:none on :hover

Animista pattern: the coral circle sets pointer-events: none while hovered, so hit-testing falls through to the underlay. The overlay should stick to the circle, not thrash.

(visible when circle ignores hits)

Expect: panel stays on the coral circle; no wild throb.

2. Continuous scale animation

Layout size (offsetWidth) stays put while the painted box grows/shrinks. Box model + highlight should not pulse with the animation.

PULSE

Expect: dashed highlight size steady; content WxH steady.

3. Hover scale (corner origin)

Grows from the bottom-left on hover. Highlight uses layout size centered on the visual box — outline won’t match the stretched paint, by design.

Hover me

Expect: no panel jump; highlight ≈ unscaled box.

4. Large hit pad over a button

Sticky inspect may keep the pad while the cursor is still in its box — even when you aim at the purple button. Drill-in to the button should still work once you’re clearly over it… unless the pad is the hit target on top.

Expect: pad sticks while cursor remains in pad box; button is inspectable when it is the event target (it’s on top).

5. Timed class toggle

Background flips every 400ms. Same-element style refresh is throttled (~200ms), so the panel may lag one beat — not freeze.

class toggle

Expect: panel color updates, slightly lagged, no thrash.

6. Nested LI → A → SPAN

Moving within nested text should prefer the deeper target (descendant drill-in), not get stuck on the outer LI.

  • Nested

Expect: hovering the label inspects SPAN or A, not only LI.
