Style Detective

Inspect CSS properties of any element on a page in real time — hover to reveal, freeze to study, copy to take with you.

How to Use

  1. Click the toolbar icon or press Alt+Shift+S (Windows/Linux) or Option+Shift+S (macOS) to enable Style Detective on the current page.
  2. Hover any element to inspect its computed CSS in the floating panel.

To customize the toggle shortcut, open Manage Extensions in your browser, then select Keyboard Shortcuts in the left sidebar.

Tip

Press F to freeze the panel in place and Esc to disable it. Freezing lets you click class chips and copy property values to the clipboard.

Keyboard Shortcuts

  • F Freeze / unfreeze the panel in place
  • C Copy the selected element's CSS to the clipboard
  • Shift+C Copy the element's classes to the clipboard
  • L Show / hide the Classes row (same as Show CSS Classes in Settings)
  • +/- Increase or decrease the panel font size. Press 0 (zero) to reset to the default size.
  • S Open this settings page
  • Esc Disable the viewer

Privacy

Style Detective needs access to the current page so it can read styles. It neither collects nor transmits any of your private data.

Settings

  • Panel Theme

    Color scheme for the inspection overlay. System follows your OS appearance and is the default.

  • Show a DevTools-style margin / border / padding diagram in the Box section. When off, those values appear as normal property rows.

  • Show a Classes row with clickable chips on elements that have classes. Toggle anytime with L while inspecting. Shift+C still copies classes when the row is hidden.

  • Number of lines of CSS classes to display before collapsing into +N more. Default is 3.

  • Base font size for the overlay (px). Same as +/- while inspecting; 0 resets to default.
